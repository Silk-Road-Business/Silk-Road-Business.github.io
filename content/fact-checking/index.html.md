# 事实核查

说明丝路商讯在发布文章和企业资料前如何核对事实、来源与时间信息。

## Body

核查对象   核查重点包括企业名称、国家或地区、行业、业务能力、来源链接、发布日期、审核日期、企业资料核验日期，以及会影响用户判断的关键事实。   核查方式   编辑流程会优先查看原始来源和公开记录；企业资料会结合企业提交信息、公开网页和编辑核验记录处理。无法确认的内容应降级表述、保留来源说明，或不发布。   时间字段   文章的审核日期应来自明确的 ReviewedAt 字段，企业资料的核验日期应来自 VerifiedAt 字段；不得把内容源的最后编辑时间当作业务审核或核验日期。
