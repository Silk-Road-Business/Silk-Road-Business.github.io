# 拥50年工业底蕴　马六甲可成半导体重镇

- Language: zh-CN
- Type: post
- Review Status: published
- Canonical: https://silushangxun.com/insights/malacca-semiconductor-hub-industrial-legacy/

马来西亚上市公司联合会总会长苏进权指出，马六甲凭借50年工业底蕴和半导体生态，可进一步把握工业算力与数据中心带来的新机遇，构建绿色智能产业生态。

## Body

FPLC总会长苏进权表示，随著半导体工业的持续发展，马六甲可结合数据中心及能源基础设施，打造更完整的绿色智能产业生态。   （马六甲17日讯）马来西亚上市公司联合会（FPLC）总会长丹斯里苏进权指出，半导体与数据中心是数码化时代相辅相成的"双引擎"，马六甲可凭借现有的半导体生态，进一步把握工业算力与数据中心带来的新机遇。   苏进权今日发表文告，赞扬马六甲首席部长拿督斯里阿都拉勿在推动该州成为先进半导体科技枢纽的远见与努力。   建立绿色智能产业生态   他说，马六甲拥有50年的工业底蕴，州政府继续推进半导体产业是正确方向，也能提升州内经济价值。   "要让产业发展迈向更高层次，相关配套必须同步跟进，以全面支撑晶片设计、智能制造及工业数据分析等高端价值链。"   他表示，州政府可考虑把半导体、数据中心、再生能源、电网容量及人才培训纳入整体规划，构建相互衔接的绿色智能产业生态。   "未来的半导体竞争，不只在生产线上，也在研发、数据和算力层面。因此，数据中心应成为服务半导体和先进制造的基础设施，让算力协助企业提升自动化、生产效率及创新能力。"   创造3大有利条件   苏进权分析，马六甲半导体与先进制造业持续壮大，已为布局工业算力与数据设施创造了三项有利条件。   首先是高端工程人才的基础。他解释，该州具备一定数量的电子、电气及工程人才，可为相关项目提供人力基础，但仍须加强网络系统、冷却技术、设施管理及数据安全等专业培训。   "其次是基建共生与协同效应。数据中心与半导体工厂同样高度依赖稳定的电力、水源及和网络连接。因此有必要统筹基础设施配套，为投资者提供更可靠且可持续的营运条件。"   "最后是庞大的实际应用场景。马六甲半导体和制造业集群的真正价值，在于创造算力的实际需求，使数据中心服务智能制造，突破单纯的托管与储存功能。"   形成独特竞争定位   苏进权表示，随著半导体与先进制造业持续发展，该州对算力、云端及数据服务的需求将日益扩大，有望在全国乃至区域，形成独特的竞争定位。   "马六甲的核心优势，除了拥有50年的工业基础，也在于能够让数据中心直接服务实体产业，把算力转化为生产力与竞争力，为本地企业与供应链开拓全新商机。"
