# MCTE将于9月17日在马来西亚吉隆坡开幕，涵盖建材五金与食品饮料

- Language: zh-CN
- Type: post
- Review Status: published

MCTE展期为9月17日至19日，相关专展涵盖建材五金和食品饮料。计划到场的企业可按产品范围筛选专展，并确认入场及现场安排。

## Body
